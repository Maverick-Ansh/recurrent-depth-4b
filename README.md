# recurrent-depth-4b

A from-scratch reproduction of **"Scaling up Test-Time Compute with Latent
Reasoning: A Recurrent Depth Approach"** (Geiping et al., [arXiv:2502.05171](https://arxiv.org/abs/2502.05171)),
plus a retrofit of the architecture onto a pretrained **4B** model.

Work in progress. See `REPORT.md` for claims, method and results.
